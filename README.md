# Energy Rating Studio

Modern React + Serverless (Vercel) website for Energy Rating Studio.  
Includes contact form integrated with Zoho SMTP via API route.

## Features
- React frontend hosted on Vercel
- API routes using Node.js (contact form)
- Zoho Mail SMTP integration (with app password)
- Responsive design and hero sections
- Deployed on: https://energyratingstudio.com.au
